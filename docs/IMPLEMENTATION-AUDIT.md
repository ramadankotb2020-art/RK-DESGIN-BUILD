- النسخة المنشورة: https://rk-desgin-build-2an.pages.dev/؛ الهوية الحالية داكنة وذهبية، خط Cairo واتجاه عربي RTL. الحفاظ على الصور والهوية والمحتوى الأساسي.
- الصفحات التسويقية: الرئيسية، عن رمضان، داخلي، خارجي/لاندسكيب، جرافيك، تواصل. الأدوات: مخطط الغرف الكبير المستقل، ومعاينة 3D. قالب تفاصيل المشروع JavaScript فقط. لوحة إدارة Cloudflare/KV منفصلة وغير متزامنة مع تدفق الفولدرات.
- المصدر المناسب لطريقة المستخدم: صور داخل images/projects-by-name + info.txt، ثم scripts/build-projects.js. الحفاظ على ذلك بدل إدخال CMS جديد.
- أول فحص Chromium محلي عند 390px: scrollWidth=394 مقابل viewport=390، مع بطاقة إحصائية خارج حدود العرض وقائمة مخفية بإزاحة خارج الشاشة. Hero ثابت الارتفاع وتداخل قواعد موبايل متكررة. إخفاء محتوى reveal افتراضيًا يجعل غياب JavaScript/تعطله يخفي أجزاء الصفحة.
- صفحات المشاريع لا تحتوي HTML مستقلًا أو OG مخصصًا؛ canonical يستخدم دومينًا مختلفًا عن الرابط الذي حدده صاحب الموقع. بيانات الصور بلا أبعاد. عنوان ووصف مشاريع كثيرة مجرد اسم المشروع؛ لن يتم اختراع قصص أو مواقع أو نتائج.
- الفيديو التلقائي من الصور أُلغي في الطلب السابق ويظل ملغى. لن يتم تشغيل ضغط وسائط الإنتاج أثناء التطوير لتجنب تعديل الملفات الأصلية.
- Facebook: لا يوجد نشر متكامل. الحل المقترح نشر اختياري من GitHub Actions بعد التحقق من نشر رابط المشروع، باستخدام Meta Graph API وGitHub Secrets وسجل دائم في GitHub Issues لمنع إعادة الإرسال. لا حاجة إلى Backend مدفوع. يتطلب إعداد Meta/صلاحيات وحدود خطط الأطراف الخارجية.
